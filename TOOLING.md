# Tooling

## `make` (app/Makefile)
- `make` / `make all` → `out.8xk` + `out.prof` (requires `out.map` as intermediate)
- `engine_resident.lib` contains sources in `engine/resident/`, including code copied to RAM by `engine/resident/install.asm`.
- `engine_page.lib` contains optional ROM routines from `engine/page/*.asm`. z88dk selects whole source modules on demand when this library is linked; the first page currently links it without using any modules.
- `make clean` → removes `*.o *.lis *.map out* struct_offsets.inc`

## `tooling/asm_lint.py`
- `python tooling/asm_lint.py check` — lint `.asm/.inc` (4-space indent, no tabs)
- `python tooling/asm_lint.py format` — auto-format
- Skips `AUTOGENERATED FILE` headers.

## `app/struct_to_asm.py` — `//#[ASM_EXPOSED]`
- Scans `app/**/*.c|h` for `//#[ASM_EXPOSED]` above `typedef struct/union`.
- `python struct_to_asm.py --list` → files with marker (used as Makefile deps)
- `python struct_to_asm.py --gen-inc` → stdout `struct_offsets.inc` (`DEFC <Struct>_<field> = <off>`, `DEFC <Struct>_size`)
- Generated via `zcc +ti83p -c -a` offsetof/sizeof (no host compiler). Manual build: `make struct_offsets.inc`.

## `app/profile_gen.py` / `tooling/profile_gen.py` — `#[PROFILE_*]` → `out.prof`
- Markers:
  ```asm
  ;#[PROFILE_ROUTINE]
  label:
  ;#[PROFILE_START <name>]
  start_label:
  ;#[PROFILE_STOP <name>]
  end_label:
  ```
  ```c
  //#[PROFILE_ROUTINE]
  void func(){}
  ```
  Assembly requires label immediately after marker (blank/comment lines allowed). C only `PROFILE_ROUTINE`.
- `python profile_gen.py --list` → annotated files (Makefile deps)
- `python profile_gen.py --regions` → parsed debug dump
- `python profile_gen.py --gen-regions --map out.map` → `out.prof` (wxWabbitemu `regions.txt` format)
  - Resolves addresses from `out.map` (`addr`+`const` ≥0x4000, handles `PHASE` RAM at `0x8000`/`0xC000` and `@local` → `global@local` scoping by file+line proximity)
  - Emits `flash:0:0xXXXX` (relative page) / `ram:3:0xXXXX` (`$8000` bank) / `ram:1:0xXXXX` (`$C000` bank) (`offset = addr & 0x3FFF`):
    `start-ret <name> <point>` / `start-end <name> <start> <end>`
  - RAM pages are the emulator's masked `bank->page` indices (see wxwabbitemu `83psehw.c` port5/port7 + `profiler/profiler.c`): TI `$83` → `3` at `$8000`, TI `$81` (written as `1` to port 5) → `1` at `$C000`; must agree with `core/ram_manager.asm:init_ram`
- `make out.prof` — autogenerated after linking. Depends on `--list` + `out.map`.

## `tooling/midi_to_audio.py` — MIDI to Audio Engine Converter
- Converts standard MIDI songs (`.mid`/`.midi`) into TI-Tale dual-channel audio engine bytecode.
- **Voice allocation & polyphony reduction**:
  - `--strategy smart` (default): Melodic line separation with bass tracking, continuity smoothing, and dynamic voice allocation.
  - `--strategy melody-bass`: Direct top-line melody to Channel 1, bass root to Channel 2.
  - `--strategy arpeggio`: Chiptune rapid chord arpeggiation (30Hz/60Hz) for chords.
  - `--strategy tracks`: Explicit user track routing via `--ch1-track <N> --ch2-track <M>`.
- **Waveform & timbre selection**:
  - Square wave: `--duty-cycle 50%|25%|12.5%`
  - Sawtooth: Additive Saw (Style 1), Exponential Saw (Style 2 & 3)
  - Timbre preferences: `--ch1-voice auto|square|saw1|saw2|saw3`, `--ch2-voice ...`
- **Custom instruments**:
  - `--custom-instruments allow|disable` (or `--allow-custom-instruments` / `--no-custom-instruments`):
    - When allowed: synthesizes 1-bit pulse tables (`ALIGN 256`) and emits `note_chX_instr` opcodes.
    - When disabled (default): restricts output to standard position-independent synth opcodes.
- **Percussion (MIDI Channel 10)**:
  - `--percussion synth|custom|none`: Synthesizes pitch-swept kick drums, saw noise snares, and metallic hi-hat ticks; temporarily preempts Channel 2 and seamlessly restores background notes.
- **Tuning, timing, articulation & envelopes**:
  - `--transpose auto|<semitones>`: Automatic whole-octave transposition to calculator sweet spot (~65 Hz to 2000 Hz).
  - `--decay auto|sweep|duty|both|none`: Musical envelope and pitch sweep decay on sustained notes/chords (prevents long static buzzy drones on 1-bit hardware).
  - `--decay-threshold <sec>`: Minimum note duration (default 0.75s) to trigger decay modulation.
  - `--decay-rate slow|medium|fast`: Pitch decrease sweep rate (`slow`=7.5Hz, `medium`=15Hz, `fast`=30Hz).
  - `--arpeggio-sustained`: Intelligently arpeggiates sustained multi-note chords so all inner chord tones ring out.
  - `--articulation <frames>`: Inserts crisp note rests between repeated identical notes (default 1 frame ~16ms).
  - `--loop`: Seamless song looping via `note_jump` opcode.
  - `--tempo-scale <mult>`: Global playback speed adjustment.
- **Outputs**:
  - `--format asm|c|bin|all`
  - `--info`: Diagnostic breakdown of tracks, channels, instruments, pitch ranges, and timing.
- **Tests**: `python tooling/test_midi_to_audio.py`

## `tooling/audio_emulator.py` — Audio Engine Emulator & Comparison Tool
- Cycle-accurate software simulation of the TI-Tale 1-bit dual-channel sound system.
- **Hardware emulation**:
  - Timer 3 (Channel 1, port `$36`) and Timer 2 (Channel 2, port `$33`) at 32,768 Hz / 234,375 Hz.
  - Phase-continuous synthesis across 60 Hz frame boundaries (eliminates frame-reset buzzing artifacts).
  - Square wave duty cycles (50%, 25%, 12.5%).
  - Additive Saw (Style 1), Exponential Saw (Style 2 & 3).
  - Hardware frequency pitch sweeps (`note_chX_square_sweep`, `note_chX_saw_sweep`) hooked to 60 Hz greyscale counter with seamless pitch slides.
  - 1-bit custom instrument pulse table playback (`note_ch1_instr`, `note_ch2_instr`).
  - Bytecode interpreter and state machine (`OP_WAIT`, `OP_STOP_SONG`, `OP_JUMP`).
- **Comparative analysis**:
  - Compares converted emulated audio against ground-truth MIDI reference audio.
  - Renders 16-bit stereo 44.1 kHz WAV (Ch1 on Left, Ch2 on Right).
  - Metrics:
    - **Timing Skew & Duration**: Frame-accurate duration matching.
    - **Pitch Tuning Error**: Mean and maximum cents error measuring hardware timer divisor accuracy against 12-tone equal temperament.
    - **Polyphony Coverage**: Percentage of MIDI notes successfully rendered across 2 channels.
    - **Channel Duty Cycle**: Active sound generation percentage on each link-port pin.
    - **Audio Envelope Correlation**: Sub-frame energy envelope correlation between emulated and ground-truth audio.
  - Multi-setting benchmarking (`--compare-settings`):
    - Evaluates `Smart (Synth Sweeps)`, `Smart (Custom Instruments)`, `Melody-Bass`, and `Arpeggio` side-by-side in a comparative matrix.
- **Usage**:
  ```bash
  # Emulate MIDI and run comparative analysis:
  python tooling/audio_emulator.py tooling/samples/adventure_theme.mid --compare

  # Compare multiple converter settings side-by-side:
  python tooling/audio_emulator.py tooling/samples/adventure_theme.mid --compare-settings

  # Emulate standalone Z80 ASM bytecode:
  python tooling/audio_emulator.py tooling/samples/theme_synth.asm -o theme.wav
  ```
