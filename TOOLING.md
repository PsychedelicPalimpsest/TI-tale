# Tooling

## `make` (app/Makefile)
- `make` / `make all` → `out.8xk` + `out.prof` (requires `out.map` as intermediate)
- `engine_resident.lib` contains sources in `engine/resident/`, including code copied to RAM by `engine/resident/install.asm`.
- `engine_page.lib` contains optional ROM routines from `engine/page/*.asm`. z88dk selects whole source modules on demand when this library is linked; the first page currently links it without using any modules.
- `make clean` → removes `*.o *.lis *.map out* struct_offsets.inc`

## `tooling/asm_lint.py`
- `python tooling/asm_lint.py check` — lint `.asm/.inc` (4-space indent, no tabs)
- `python tooling/asm_lint.py format` — auto-format
- Skips `AUTOGENERATED FILE` headers.

## `app/struct_to_asm.py` — `//#[ASM_EXPOSED]`
- Scans `app/**/*.c|h` for `//#[ASM_EXPOSED]` above `typedef struct/union`.
- `python struct_to_asm.py --list` → files with marker (used as Makefile deps)
- `python struct_to_asm.py --gen-inc` → stdout `struct_offsets.inc` (`DEFC <Struct>_<field> = <off>`, `DEFC <Struct>_size`)
- Generated via `zcc +ti83p -c -a` offsetof/sizeof (no host compiler). Manual build: `make struct_offsets.inc`.

## `app/profile_gen.py` / `tooling/profile_gen.py` — `#[PROFILE_*]` → `out.prof`
- Markers:
  ```asm
  ;#[PROFILE_ROUTINE]
  label:
  ;#[PROFILE_START <name>]
  start_label:
  ;#[PROFILE_STOP <name>]
  end_label:
  ```
  ```c
  //#[PROFILE_ROUTINE]
  void func(){}
  ```
  Assembly requires label immediately after marker (blank/comment lines allowed). C only `PROFILE_ROUTINE`.
- `python profile_gen.py --list` → annotated files (Makefile deps)
- `python profile_gen.py --regions` → parsed debug dump
- `python profile_gen.py --gen-regions --map out.map` → `out.prof` (wxWabbitemu `regions.txt` format)
  - Resolves addresses from `out.map` (`addr`+`const` ≥0x4000, handles `PHASE` RAM at `0x8000`/`0xC000` and `@local` → `global@local` scoping by file+line proximity)
  - Emits `flash:0:0xXXXX` (relative page) / `ram:3:0xXXXX` (`$8000` bank) / `ram:1:0xXXXX` (`$C000` bank) (`offset = addr & 0x3FFF`):
    `start-ret <name> <point>` / `start-end <name> <start> <end>`
  - RAM pages are the emulator's masked `bank->page` indices (see wxwabbitemu `83psehw.c` port5/port7 + `profiler/profiler.c`): TI `$83` → `3` at `$8000`, TI `$81` (written as `1` to port 5) → `1` at `$C000`; must agree with `core/ram_manager.asm:init_ram`
- `make out.prof` — autogenerated after linking. Depends on `--list` + `out.map`.
